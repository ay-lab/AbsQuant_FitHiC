# ---------------------------------------------------------------------------
# Example FITHIC_FILE_LIST for 1.4_intersect_replicates.sh
#
#   FITHIC_FILE_LIST=examples/fithic_files.example.txt bash 1.4_intersect_replicates.sh
#
#   sbatch --export=ALL,FITHIC_FILE_LIST=examples/fithic_files.example.txt \
#     1.4_intersect_replicates.sh
#
# Copy this file, point the paths at your own fithic output, and pass it in.
# It replaces both FITHIC_DIR and REPLICATE_NAMES: when a manifest is given,
# nothing is derived and only the files listed here are used.
# ---------------------------------------------------------------------------
#
# FORMAT
#   Blank lines and everything after a '#' are ignored.
#   Each remaining line is one of:
#
#     <path>                 intersect this file against EVERY condition
#     <condition>  <path>    intersect it against that ONE condition only
#
#   <condition> must match an entry in SUBSETS.
#   Paths may be absolute or relative to where you run the script from, and
#   may be plain text or .gz - both are read directly. Paths must not contain
#   spaces or '#'.
#
#   A file that does not exist is reported and skipped, not fatal; a '.gz'
#   alongside a listed plain path is picked up automatically.
#
# ---------------------------------------------------------------------------
